# Security

This repository only contains the OkkMax plugin manifests, the MCP connection configuration and two Agent Skills. The MCP server at https://www.okkmax.com/mcp is read-only: its tools only look up data and never write, buy, top up or change an account.

## Reporting a problem

Report security problems through GitHub's private vulnerability reporting for this repository (Security tab, "Report a vulnerability"). If that is not available to you, use the contact options on https://www.okkmax.com/support.

Please do not put sensitive details in a public issue. A useful report includes the affected file or tool, the steps to reproduce it, what you expected and what happened.

Non-sensitive bugs, wrong data and wording problems can be public issues. Data corrections for a relay are handled through https://www.okkmax.com/support.
